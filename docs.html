Docs

Everything you need to connect a source, point an AI at your Junie link, and start asking real questions about your own data.

Quickstart

Three steps, about two minutes end to end.

  1. Create a free account and connect at least one source (ring, watch, CGM, or gym log).
  2. Copy your private MCP link from the dashboard — it looks like https://junie.health/u/8f2c/mcp.
  3. Paste that link into Claude, ChatGPT, or any client that speaks MCP, then ask a question.
Your link is unique to your account and unlisted. Anyone with it can read your connected data, so treat it like a password — you can rotate it any time from Settings.

Connecting sources

Each source connects through OAuth directly with the provider — Junie never sees or stores your provider password. Access is read-only and can be revoked from either side at any time.

Supported categories

  • Labs & bloodwork — LabCorp, Quest Diagnostics, Function Health
  • Rings & watches — Oura, Garmin Connect, WHOOP, Polar, Suunto, Withings, Ultrahuman, Fitbit, Coros, and international devices in beta (Amazfit, Xiaomi Mi Band, Huawei Health)
  • Glucose, power & effort — Dexcom (alpha), Wahoo, Concept2, Intervals.icu
  • Nutrition & food logging — MyFitnessPal, Cronometer
  • Strength & training logs — Hevy, Apple Health, Health Connect
  • Home & sleep environment — Eight Sleep, Airthings

Don't see a source you use? Request it from the Sources page and it moves up the build queue.

Adding an AI client

Junie speaks MCP (Model Context Protocol), so it works the same way in any client that supports custom connectors.

Claude

Open Settings → Connectors → Add custom connector, and paste your Junie link. Claude will list the available tools automatically.

ChatGPT

Under Settings → Apps & connectors, choose "Add connector" and paste the same link.

Any other MCP client

Point the client's connector configuration at your link:

// mcp-config.json
{
  "mcpServers": {
    "junie": {
      "url": "https://junie.health/u/8f2c/mcp"
    }
  }
}

Available tools

Once connected, your AI client can call:

  • list_metrics — returns every metric available across your connected sources
  • query_metrics — fetches values for named metrics over a date range
  • get_profile — returns account info, connected sources, and plan tier
  • sync_source — triggers an incremental sync for one provider

Scopes & permissions

Every tool call is read-only by design. Junie cannot post a workout, change a device setting, or take any action on your behalf on the provider's side. Full call history is available in your account's audit log.

Personal API

Pro accounts also get raw JSON access for building your own dashboard, spreadsheet sync, or model.

curl https://junie.health/api/v1/metrics \
  -H "Authorization: Bearer YOUR_TOKEN"

See For developers for authentication details and rate limits.
