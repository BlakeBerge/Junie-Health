AI & agents

Let an AI agent read your health data — on request, nothing standing.

This is a real MCP (Model Context Protocol) server. Any MCP-compatible client — Claude Code, Claude Desktop, or others — can connect with a personal token and query your connected sources, logs, and computed score. Read-only. Revoke a token any time and it stops working immediately.

Your MCP URL

https://junieai.netlify.app/mcp

This is a real OAuth-capable MCP server. Two ways to connect:

One clickIn Claude's Settings → Connectors → Add custom connector, paste the URL above. Claude registers itself automatically and takes you to a Junie sign-in + consent screen — no token to copy.
Manual tokenFor clients that don't support OAuth discovery (e.g. Claude Code's mcpServers config), generate a token below and use it directly:
{ "mcpServers": { "junie-health": { "url": "https://junieai.netlify.app/mcp", "headers": { "Authorization": "Bearer YOUR_TOKEN" } } } }

What it can do — read-only, three tools:

list_metricsLists which metric types you actually have synced, grouped by source.
query_metricsPulls raw values for specific metrics over a date range.
get_health_scoreComputes your real score breakdown — same methodology as the Health Audit page, not a separate number.
