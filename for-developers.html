For developers & agent builders

Build automations on top of your own vitals.

Junie isn't just a chat connector. Every tool it exposes to Claude or ChatGPT is also callable directly, so you can wire scheduled agents, dashboards, or your own product on top of the same feed.

Three ways to build

Pick the surface that matches what you're making.

Scheduled agents

Point a cron-triggered agent (OpenClaw, a Claude Code job, your own script) at your MCP link and have it check readiness every morning, then message you when something drifts.

Personal API

Pull raw JSON with a bearer token. No MCP client required — good for dashboards, spreadsheet syncs, or feeding your own model.

MCP tools

Call list_metrics, query_metrics, get_profile, and sync_source directly from any MCP-aware agent framework.

Authenticate

Generate a token from Settings → Developer, then send it as a bearer token on every request.

const res = await fetch("https://junie.health/api/v1/metrics?metric=hrv&days=30", {
  headers: { Authorization: `Bearer ${process.env.CORPUS_TOKEN}` }
});
const data = await res.json();

Example: a morning readiness agent

A minimal scheduled job that checks HRV against baseline and only messages you when it's genuinely low.

// runs on a daily schedule, e.g. via cron or an agent framework
const { hrv, baseline } = await junie.query_metrics({
  metrics: ["hrv", "hrv_baseline_30d"],
  days: 1
});

if (hrv < baseline * 0.85) {
  notify(`HRV is ${Math.round((1 - hrv/baseline) * 100)}% below baseline — consider an easy day.`);
}
